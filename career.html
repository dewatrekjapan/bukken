あなたの投稿・メール・行動履歴から「考え方と目標」をモデル化し、国内外のトレンドと掛け合わせて、いま起こすべきアクションと機会を導き出す

プロフィール（任意）

職業・スキル・制約条件・今の状況など。ライフデータの解釈の土台になります。

ライフデータを追加

SNS投稿、送信メール、日記・メモ、行動ログ（予定・購入・閲覧など）を貼り付け。1件ずつでも、空行2つ区切りの一括貼り付けでも可。

対応：テキスト／CSV／JSON（X の tweets.js、汎用JSON配列）。ファイル内容はブラウザ内でのみ処理され、分析実行時に Anthropic API へ送られます。

この仕組みについて

①ライフデータ（SNS投稿・送信メール・行動履歴）からユーザーの考え方・キャリア観・人生の目標をモデル化し、 ②国内外の最新トレンド・市場動向・先進事例を合流させ、 ③両者を掛け合わせて、目標に近づくために今起こすべきアクション、必要な情報、最適なビジネスやコミュニティとのマッチング機会を導き出す。 データはすべてブラウザ内に保持され、分析実行時のみ Anthropic API に送信されます。
