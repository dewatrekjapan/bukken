ライフデータ × トレンド — 自己実現支援AI

投稿・送信メール・行動履歴から「考え方と目標」を継続的にモデル化し、国内外のトレンドと掛け合わせて、いま起こすべきアクションと機会を導き出す

はじめに — このツールとデータの扱い

ライフデータ（投稿・送信メール・予定など）はこの端末のブラウザ内に保存され、分析を実行したときだけ AI（Anthropic API、またはこのサービスの中継サーバー）に送信されます。運営者がデータを閲覧・保存することはありません。 送信前にメールアドレス・電話番号などは自動でマスクされます（設定で変更可）。 AI の出力は推論であり、事実確認と判断はご自身で行ってください。

Google から自動取り込み

Gmail の送信メールと Google カレンダーの予定を、ブラウザから直接（サーバーを介さず）取り込みます。2回目以降は前回同期以降の差分だけを取得します。初回は設定タブに Google OAuth クライアント ID が必要です。

プロフィール（任意）

職業・スキル・制約条件・今の状況など。ライフデータの解釈の土台になります。

ライフデータを追加

取り込み方法（自動収集に近づける手段）
  • X（Twitter）：設定 → データのアーカイブをダウンロード → data/tweets.js を読み込む。RTは自動除外。
  • Gmail の送信メール：Google Takeout でメールを mbox 形式で書き出し → .mbox を読み込む。設定タブに自分のメールアドレスを入れておくと、自分が送ったメールだけを抽出し、引用返信部分を除去する。
  • スマホから共有：このページを「ホーム画面に追加」すると、他アプリの共有メニューにこのアプリが出る。投稿や記事を共有すると本文欄に入る。
  • PCのブラウザ：このリンクをブックマークバーへドラッグ → 任意のページで選択した文章を保存 📌 ライフデータに保存
  • テキスト／Markdown は空行2つ区切り、CSV は1行1件、JSON は配列の各要素の text / body / content を本文として取り込む。

AI への接続

この端末のブラウザにのみ保存され、Anthropic API 以外には送信されません。共用PCでは保存しないでください。

API キーは中継サーバー側で管理され、利用者には配布されません。利用量の上限はコードごとに設定されます。

データの扱い

この仕組みについて

①ライフデータ（SNS投稿・送信メール・行動履歴）から本人の考え方・キャリア観・人生の目標を継続的にモデル化し（差分更新・変遷記録・根拠引用つき）、 ②自己モデルから導出した検索で国内外の最新トレンド・市場動向・先進事例を合流させ、 ③両者を掛け合わせて、いま起こすべきアクション、必要な情報、接続すべきビジネスやコミュニティを導き出す。 提案への反応（着手・完了・却下）は次回の入力として学習に使われる。 データはすべてブラウザ内に保持され、分析実行時のみ Anthropic API に送信される。
